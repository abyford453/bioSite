# CSD 340 Web Development with HTML and CSS

Stephanie M. Friedman bioSite — a three-page personal biography project featuring her accomplishments, professional journey, and travel interests.

## Contributors

- Dr. Mortoza Abdullah
- Armond Drew Byford

## Project pages

- `index.html` — landing page and accomplishments
- `about.html` — portrait and biography
- `hobbies.html` — travel interests and destinations
- `site.css` — shared design system, responsive layouts, and component styles

## Design system

The site follows an atomic design approach: colors, typography, spacing, buttons, and links (atoms); navigation links and photo cards (molecules); header, hero, card gallery, and footer (organisms).

## Preview

Open `index.html` locally, or publish the `main` branch using GitHub Pages. The three pages link to each other.

## Image notes

Four images were supplied for the subject's personal bioSite. The Rome, Santorini, and Bahamas images are original *concept illustrations*, not photos of her travels. Replace them with licensed or personally owned destination photographs for the final website if required. Newspaper coverage is credited in the site.

## Validation

Before submitting, validate each HTML page using https://validator.w3.org/nu/ and the stylesheet using https://jigsaw.w3.org/css-validator/. Correct any reported errors and save screenshots if requested.
